Class Bank

A personal finance learning app for checking a balance, recording deposits and withdrawals, and reviewing recent transactions.

Project Overview

Class Bank is a small banking simulation built to practice Android app development and local data persistence. The Android version uses Kotlin, Jetpack Compose and SQLite; a separate Python command-line version explores the same basic banking flow.

Key Features

  • View the current account balance
  • Record deposits and withdrawals
  • Review recent transactions
  • Store account and transaction data locally with SQLite

Technology Stack

Kotlin
Jetpack Compose
SQLite
Python
