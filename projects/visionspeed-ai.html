COMPUTER VISION / VIDEO ANALYSIS

VisionSpeed AI

A desktop app that analyzes video for people, vehicles and common objects, then saves annotated output and CSV summaries.

Traffic Analysis Preview

Project Overview

VisionSpeed AI provides a desktop workflow for selecting a video, choosing an analysis mode and reviewing object detections. It uses an Ultralytics YOLO model with ByteTrack tracking and can export an annotated video and a CSV summary.

Key Features

  • Vehicle, person and generic object analysis modes
  • Adjustable speed and detail settings
  • Object tracking with ByteTrack
  • Optional annotated video and CSV summary output

Technology Stack

Python
Ultralytics YOLO
OpenCV
ByteTrack
Tkinter
