Dragon Mouse

An animated dragon that follows the mouse, built as an interactive Python and Pygame experiment.

Project Overview

Dragon Mouse explores procedural motion and character animation. A chain of body segments follows the pointer with smooth bends, while themes and optional motion trails change the visual feel.

Key Features

  • Pointer-following movement
  • Procedurally animated body segments
  • Selectable visual themes
  • Optional motion trails

Technology Stack

Python
Pygame
Procedural animation
