Scorpion

A mouse-controlled scorpion animation with a segmented body and smooth procedural movement.

Project Overview

Scorpion is a compact Pygame experiment focused on drawing and animating a creature that responds to pointer movement. Its segmented body uses curved motion to create a fluid follow effect.

Key Features

  • Pointer-controlled movement
  • Segmented body animation
  • Smooth curve-based motion
  • Standalone Python desktop experience

Technology Stack

Python
Pygame
Procedural animation
