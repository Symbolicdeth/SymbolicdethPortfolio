COMPUTER VISION / DESKTOP APP

Label Inspection

A camera-based desktop tool for inspecting product labels and comparing captured images with reference products.

Project Overview

Label Inspection combines a live camera feed with image processing tools for examining product packaging. The project includes product reference data and experiments for locating and comparing label regions.

Key Features

  • Live camera capture
  • Product and reference image data
  • Image processing experiments
  • Desktop interface built with Tkinter

Technology Stack

Python
OpenCV
NumPy
Tkinter
